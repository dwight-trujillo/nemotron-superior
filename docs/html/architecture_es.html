🗄️ Modelo de Datos Bitemporal (GDPR)

Tabla: prompts
├── id (UUID)
├── content (TEXT)
├── valid_from (TIMESTAMP)  ← inicio vigencia
├── valid_to (TIMESTAMP)    ← NULL = vigente actual
└── deleted_at (TIMESTAMP)  ← soft delete

Cada cambio crea una NUEVA fila con valid_to actualizado.
