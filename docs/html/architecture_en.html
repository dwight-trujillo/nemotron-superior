🗄️ Bitemporal Data Model (GDPR)

Table: prompts
├── id (UUID)
├── content (TEXT)
├── valid_from (TIMESTAMP)  ← validity start
├── valid_to (TIMESTAMP)    ← NULL = currently valid
└── deleted_at (TIMESTAMP)  ← soft delete

Each change creates a NEW row with updated valid_to.
