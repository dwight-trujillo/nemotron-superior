🚀 Guía de Instalación Rápida

📦 1. Requisitos previos

  • Docker 24+ y Docker Compose 2.20+
  • 8GB RAM mínimo (16GB recomendado)
  • Python 3.12+ (para desarrollo local)

🐳 2. Levantar con Docker (recomendado)

git clone https://github.com/dwight-trujillo/nemotron-superior.git
cd nemotron-superior
cp .env.example .env
# Edita .env con tus valores
docker-compose up -d

🐍 3. Instalación local (desarrollo)

python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
pip install -r requirements.txt
uvicorn src.infrastructure.web.app:app --reload

🔧 4. Variables de entorno obligatorias

JWT_SECRET_KEY=tu-clave-secreta-minimo-32-caracteres
ENCRYPTION_KEY=base64-encoded-32-byte-key
DATABASE_URL=postgresql+asyncpg://user:pass@localhost:5432/nemotron
REDIS_URL=redis://localhost:6379/0

✅ 5. Verificar instalación

curl http://localhost:8000/health
# Respuesta esperada: {"status":"healthy"}
